# S-Tiermix 

S-Tiermix is a web app that helps users create Spotify playlists effortlessly.  
Enter your favorite songs, and the app generates a curated playlist of recommended tracks using the Spotify API — then adds it directly to your account.

## Features
- User-friendly interface for entering songs
- Smart playlist generation using Spotify recommendations
- Automatic playlist creation on your Spotify account
- Clean, responsive design built with HTML, CSS, and JavaScript

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- API: Spotify Web API (OAuth 2.0 Authentication)
